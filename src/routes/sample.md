# MarkEditDown

MarkEditDown is an intuitive, web-based Markdown editor designed to streamline note-taking and task management within a single, distraction-free interface. By combining a live-preview writing environment with integrated checklist tracking, it helps users convert raw ideas into organized, actionable workflows. The tool focuses on providing a clean, high-performance experience that makes complex backend logic feel simple and accessible to the end user.

## Features

* **Split-Screen Live Preview:** Write Markdown on the left, see beautifully rendered HTML on the right in real-time.
* **Synchronized Scrolling:** The edit and preview panes scroll together automatically based on percentage height.
* **Persistent Storage:** Automatically saves your draft to `localStorage` so you never lose your work when closing the tab.
* **Custom Resizable Layout:** Drag the divider to adjust the split ratio between the editor and preview modes.
* **Tailored Markdown Theme:** Custom CodeMirror syntax highlighting built around modern CSS variables.
